## 📋 Instrucciones para GitHub Pages

### Paso 1: Crear una cuenta en GitHub
1. Ve a https://github.com
2. Haz click en "Sign up"
3. Completa tu email, contraseña y usuario
4. Verifica tu email

### Paso 2: Crear un nuevo repositorio
1. Desde tu perfil de GitHub, haz click en "New" (o ve a https://github.com/new)
2. Nombre del repositorio: `melanie-xv-anos` (o el nombre que quieras)
3. Descripción: "Invitación XV años de Melanie"
4. Elige "Public" (público, para que todos vean el link)
5. Haz click en "Create repository"

### Paso 3: Subir los archivos
Tienes 2 opciones:

#### **Opción A: Subir directamente en GitHub (más fácil)**
1. En tu repositorio recién creado, haz click en "Add file" → "Upload files"
2. Arrastra la carpeta `melanie-xv-anos` completa
3. Haz click en "Commit changes"

#### **Opción B: Usar Git en tu compu (más avanzado)**
```bash
git clone https://github.com/TU-USUARIO/melanie-xv-anos.git
cd melanie-xv-anos
# Copia todos los archivos aquí
git add .
git commit -m "Invitación XV años Melanie"
git push
```

### Paso 4: Habilitar GitHub Pages
1. En tu repositorio, ve a "Settings" (arriba a la derecha)
2. En el lado izquierdo, busca "Pages"
3. Bajo "Source", selecciona "Deploy from a branch"
4. En "Branch", elige `main` y luego `/ (root)`
5. Haz click en "Save"

### Paso 5: ¡Listo! 🎉
GitHub generará un link automáticamente. Verás algo como:

```
https://tu-usuario.github.io/melanie-xv-anos/
```

Ese es el link que compartes con todos los invitados.
